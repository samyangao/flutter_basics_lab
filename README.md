# flutter_basics_lab

A Flutter project for the IT 120 Integrative Programming and Technologies 2 laboratory activities.

## Getting Started

This project contains five Flutter lab activities covering widgets, layouts, state management, themes, and reusable UI components.

To run the project:

1. Install Flutter and ensure it is available in your system PATH.
2. Open the project folder in VS Code.
3. Run `flutter pub get` in the terminal.
4. Run `flutter run -d chrome` to launch the application in Google Chrome.
